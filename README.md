# canada-prospector-media

Temporary public video hosting for Canada Prospector social posting. Threads can only take video from a public link and refuses Meta's own links, so a reel's video is put on the `threads-tmp` branch while Threads downloads it, then the branch is reset.

Nothing stays here: `main` holds only this README. The tool is `tools/threads_host.py` in the canada-prospector-video-pipeline repo.
